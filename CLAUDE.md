# CLAUDE.md

TurkC is a minimal C-like language with Turkish keywords (`eger`, `degilse`, `icin`, `iken`, `dondur`, plus `int`, `void`). This repo holds only the lexer (a Flex scanner) written for a compiler design course. There is no parser or code generator.

## Commands
- Build: `make` (runs `flex scanner.l`, then `cc lex.yy.c -o scanner`). `-lfl` is not needed because `yywrap` is defined in `scanner.l`.
- Test: `make test` (scans `test1.tc` and `test2.tc` with CRs stripped). There is no assertion framework; the README lists the expected output.
- Run: `./scanner < file.tc`
- Clean: `make clean` (removes only the `scanner` binary).

## Layout
- `scanner.l`: the only hand-written source. Each rule prints `KEYWORD|IDENTIFIER|NUMBER|STRING|OPERATOR|PUNCTUATION|UNKNOWN: <text>`.
- `lex.yy.c`: generated by Flex but intentionally tracked (course deliverable). Regenerate it with `make` after editing `scanner.l` and commit both.
- `spesifikasyon.md`: language spec (Turkish). Keep it in sync with the lexer.
- `README.md`: bilingual (English, then Turkish). Edit both halves.

## Gotchas
- `scanner.l`, `README.md` and the `.tc` samples use CRLF line endings; preserve them when editing. CRs in input show up as `UNKNOWN` tokens.
- Flex rule order matters: keywords come before the identifier rule so they win ties.
- Docs and comments are Turkish or bilingual; keep the existing language of each file.
